Ola Ride & Operations Analytics Dashboard

Project Overview

This project analyzes Ola ride and operational data to understand booking performance, ride status, vehicle types, customer and driver behaviour, and operational trends.

An interactive Power BI dashboard was developed to provide a clear overview of ride operations and help identify patterns that can support data-driven business decisions.

Business Objective

The objective of this project is to analyze ride-booking data and understand key operational factors such as booking status, vehicle type, ride volume, customer behaviour, and trip performance.

Business Questions

1)What is the total number of bookings?
2)How many bookings were completed and cancelled?
3)What is the overall booking success rate?
4)Which vehicle types receive the highest number of bookings?
5)Which pickup locations have the highest number of bookings?
6)How many booking status is distributed?
7)Which vehicle types has highest cancelled rides?
8)What is the count of customer?

Dashboard Analysis

The dashboard provides insights into:

* Total bookings
* Booking status
* Completed and cancelled rides
* Vehicle type performance
* Cancellation analysis
* Ride and operational trends
* Pickup and drop locations
* Key operational KPIs

Key Insights

* The dashboard provides an overview of overall ride-booking performance.
* Booking status analysis helps identify completed versus cancelled rides.
* Vehicle-type analysis highlights differences in demand across ride categories.
* Cancellation analysis helps identify areas where operational improvements may be required.
* Location-level analysis helps identify areas with higher ride demand.
* Interactive filters allow users to explore ride performance across different categories.

Conclusion

This project demonstrates how Power BI can be used to transform ride-booking data into meaningful operational insights.

The dashboard enables users to monitor booking performance, identify cancellation patterns, compare vehicle types, and understand ride demand to support better operational decision-making.
